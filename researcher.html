2. How allocation works

After a participant answers the gender question, the Google Sheet script picks the version: Woman = V2 (female cues), Man = V1 (male cues). Any other answer goes to whichever variation has fewer participants (remove these in data cleaning). Within each variation the group alternates G1, G2, G1, G2.... The counter lives in the Google Sheet, so it stays balanced on every device.

5. Testing

To try the experiment without affecting the counts, open the participant site with ?condition=G1V1&pid=TEST01 added to the address (change G1V1 to G1V2, G2V1 or G2V2). Test links force that version and are not counted. Test data is still saved to the sheet, so delete those rows afterwards.
